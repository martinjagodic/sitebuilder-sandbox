# Planet Plus (Ljubljana – Šmartno): research

Researched 25 Sep 2026. Every fact has its source next to it. If something isn't listed here, it wasn't found. **Nothing below is invented.** Anything inferred rather than stated by a source is labelled *(inference)*.

**Method note.** WebFetch can't render Google Maps, Facebook, Instagram or the brands' JavaScript dealer locators. For those I made plain HTTP GET requests (curl) to the same public pages or JSON endpoints the pages load themselves. That includes the brands' public search-only Algolia and WordPress store-locator endpoints, and the Nominatim API (with a User-Agent, as asked). I used no browser or DevTools tools. The Google data is the place record Google Maps returned on 25 Sep 2026.
